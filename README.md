One original line roasting the video doorbell I use every day: it films me fumbling for my keys, then bills me monthly to rewatch myself locked out of my own house.

## Run it

```sh
python3 main.py
```

The program validates the line (1 to 200 characters, not blank), writes it to `/output/entry.txt`, and reads the file back to verify it byte for byte. Standard library only.
